## 🚀 Featured Project

### 🐈 [BagheerasDream](https://bagheerasdream.de/)

A full-stack website for a **British Shorthair cattery**, developed as an independent real-world project.

- Built with **C#, .NET, ASP.NET Core and Blazor**.
- Structured with **Clean Architecture** and **Entity Framework Core**.
- Includes an administration area for managing cats, litters, kittens and website content.
- Deployed to a **Linux VPS** using Docker Compose and Caddy.
